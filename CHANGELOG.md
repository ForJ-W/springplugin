# Changelog

All notable changes to Spring Plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows semantic versioning for public releases.

## [v0.1.0] - 2026-06-01

### Added

- Published the Boot 3 implementation history on the main branch.
- Added OSS maintenance files, including contribution guide, code of conduct,
  security policy, roadmap, issue templates, pull request template, and CI.
- Added JDK 25 build support with Spring Boot 3.5 and Spring Cloud 2025.
- Added core, starter, server, manager, and demo modules.
- Added demo coverage for MVC, MyBatis Plus, Flyway, app plugin, and runner
  scenarios.

### Verified

- Built the Maven reactor with `mvn -B clean verify`.
